# Audit: 2026-09-23

A full audit of both plugins (7 skills), `shared/`, the Florida and Stellar market layers, the docs and the dev tooling. It was run at version 0.2.0 with 215 tests passing, `make check-sync`, `make style-check` and `claude plugin validate .` clean, and every relative doc link resolving. The problems below are mostly wrong real-estate rules and cases no fixture covers. No code was changed during the audit.

## How to read this

- **Priority.**
  - **High:** a wrong number, date or claim a client can see, a crash on a common input, or a compliance risk.
  - **Medium:** wrong on less common inputs, a logic gap, or a UX problem that misleads.
  - **Low:** cosmetic, docs, tooling, or hardening.
- **Status.**
  - **Confirmed:** reproduced by running the code or read directly in it.
  - **Reported:** found by reading the code; the reviewer is confident, but it hasn't been re-run.
  - **Verify:** depends on the current form text, a statute or county custom. Check the primary source before fixing. Results are in [2026-09-23-verification.md](2026-09-23-verification.md), which wins where it differs from this file.
- **IDs** are stable: area prefix plus number. Track fixes by ID in commits and in [status.md](../status.md).
