# Audit: 2026-09-29 (Pre-Release, 0.12.0)

A full audit before the pull request that ships 0.11.0 and 0.12.0 to `main` together (main is at 0.10.2; `git diff main..develop` is 172 files, about 20k lines). It covers the six skills, `shared/`, docs, manifests, packaging, the eval set and the test suite. It was run on `develop` at `fb6a3e0`. No skill code was changed during the audit; the dev tooling it added (golden tests, `samples_diff.py`, the release checklist) is listed at the end.

Priorities, statuses and the ID scheme follow [the 2026-09-23 audit](2026-09-23.md#how-to-read-this). IDs from 101 up are new; two new prefixes: **REL** (packaging, install, release) and **EVAL** (defects in the eval set and mock answer keys, not in the skills). Findings reported by more than one reviewer keep one ID and name the duplicate.

## Verdict

**No-go until the High items are fixed.** Every automated check passes, and every deadline the contract skills computed from a mock package matched its answer key, but five High findings are client-visible or compliance problems: the fair-housing prose check misses pregnancy and religion, three offer-pricing bugs, and a flood-zone parsing bug that prints a false insurance claim.
